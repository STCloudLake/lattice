## 1. 它是什么

Lattice 是一个**浏览器里的学习助手**。它做三件事：

1. **把你的材料拆成"命题"和"推理链"** —— 不是抽成问答卡，而是记下"哪句话是什么判断"、"哪些判断是推出另一句话的前提"。
2. **用两个数字描述你** —— 一个是「你懂没懂」（掌握度），一个是「你会不会忘」（可用率）。它们是两个东西，分开算。
3. **在你会出现的地方，安排下一件该学的事** —— 新标签页、你正在看的网页边上、系统通知，每次 15 秒。

它不替你学习，也不跟你聊天。它只负责**安排**。

### 它不是什么

- **不是 Anki 替代品**。Anki 让你管理卡片，Lattice 决定你该学什么。两者可以同时用。
- **不是 AI 聊天助手**。没有对话框。AI 只在"拆材料、认重名、出题、解释"这四个地方出现。
- **不是课程平台**。它不生产内容，只整理你自己的材料。
- **不是监控工具**。没有老师后台、没有排行榜、没有账号。

## 2. 安装

### 2.1 先确认三件事

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome 或 Edge 最新版（依赖 OPFS + MV3）。Firefox 尚未正式验证。 |
| 模型（可选） | 一个 OpenAI 兼容 API key、或 Anthropic key、或本地模型（Ollama / LM Studio）。**没有模型也能用**，只是要手动建卡。 |
| 磁盘/存储 | 扩展内数据默认几百 MB 以内；daemon 模式需要能写 `~/.lattice/` |

### 2.2 Solo 模式（推荐，90% 的用户）

**从商店安装**

1. 打开 Lattice 的商店页面 → 「添加至 Chrome」。
2. 首次打开新标签页时，浏览器会问「是否更改新标签页」→ 允许（这是 Lattice 的主界面）。

**用开发者模式安装（beta 期间）**

1. 下载发布包并解压到固定目录（**别放临时目录**，更新时会被清理）。
2. 地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 右上角打开「开发者模式」。
4. 点「加载已解压的扩展程序」→ 选择解压后的目录。
5. 建议把扩展图标**固定**到工具栏（点击拼图图标 → 图钉）。

> 数据存在浏览器的 OPFS（源私有文件系统）里，**和扩展目录无关**。更新、重新加载扩展都不会丢数据。但清理浏览器站点数据会删掉它——请定期导出（§9.2）。

### 2.3 Daemon 模式（可选，进阶）

如果你想要命令行、让其他 AI 工具读取你的学习记录、或多设备同步：

```bash
# 需要 Node.js 20+
npx @lattice/daemon init        # 初始化 ~/.lattice/
npx @lattice/daemon serve       # 启动本地服务，默认 127.0.0.1:7878
```

启动后扩展会自动发现本地服务（也可在 设置 → 数据 → 存储位置 里手动填端口）。
之后数据落在 `~/.lattice/`，扩展里显示「已连接本地服务」。

> daemon 只监听回环地址，会生成一次性 token 与扩展握手。不要在公网暴露它。

### 2.4 首次运行向导

打开新标签页，会依次问你六件事：

1. **选择模型**（可跳过）——填 key 或选本地模型，点「测试连接」。
2. **你的第一个目标**（可跳过）——例如"三周后期末考到 85 分"。
3. **推送强度** —— 保守 / 平衡 / 积极。**新手建议选保守**（默认）。
4. **允许的表面** —— 新标签页（默认开）、页内角标（默认开）、系统通知（默认关）。
5. **安静时段** —— 默认 23:00–08:00 不打扰。
6. **是否接受留白对照** —— 默认开，见 §8.4。不想要可以关。

## 3. 五分钟上手

### 第 1 分钟：装好、打开新标签页

你会看到一张卡（如果没有材料，会提示你导入）。顶部有三个入口：

```
Lattice                    [今日 3]  [前沿 12]  [复习 7]      ⚙
```

- **今日**：今天为你安排的卡（复习 + 新学）
- **前沿**：现在就可以学的命题（先修条件已满足）
- **复习**：到期需要复习的数量

### 第 2–3 分钟：放一份材料进去

**方式一（最快）**：打开任意网页，选中一段文字 → 右键 → **「存入 Lattice」**。

**方式二**：点扩展图标 → 「添加材料」→ 把 PDF 拖进去。

**方式三（没有模型时）**：点扩展图标 → 「手动建卡」→ 输入一个问题和答案。

放进去之后：
1. 先出现的是**候选清单**，不是直接入库；
2. 你可以逐条勾选/删除/改文字；
3. 点「确认入库」后，它们才变成正式命题。

### 第 4 分钟：复习第一张卡

会看到类似：

```
┌────────────────────────────────────────┐
│  边际效用为什么递减？                    │
│                                        │
│  [ 重来 ]  [ 困难 ]  [ 一般 ]  [ 简单 ]  │
│                             为什么是这张？│
└────────────────────────────────────────┘
```

先在心里回答，再点「显示答案」，然后按你的实际感受选一档。**诚实比正确重要**——
选高了，下次它很久才出现，你会忘；选低了，你会被过度打扰。

### 第 5 分钟：看看它怎么理解你

点右上角 ⚙ → 「数据」→ 「我的模型」，你会看到每个命题两个数：

| 命题 | 掌握度 | 可用率 | 解读 |
|---|---|---|---|
| 边际效用递减 | 72%（±12） | 61% | 懂了，但快忘了 → 该复习 |
| 机会成本 | 88%（±6） | 95% | 既懂又稳 |
| 纳什均衡 | 34%（±18） | 80% | 背得住，但没真懂 → 该补先修 |

最后一行是关键：**这就是它和只有"熟练度"的工具不同的地方。**

## 4. 核心概念

用生活化的话解释，术语表见 §17。

### 4.1 命题（proposition）

**一个可以被"信以为真"的判断句。**

- "边际效用递减" 是命题。
- "经济学" 不是命题（是领域名词）。
- "消费者在预算约束下最大化效用" 是命题。

为什么要拆这么细？因为只有判断句才能被"懂"或"不懂"，才能被推理链连接。

### 4.2 推理链（chain）

**几个前提合在一起，推出一个结论。**

比如："预算有限 + 每单位货币的边际效用递减 + 消费者追求效用最大化" ⟹ "需求曲线向右下倾斜"。

注意：**前提是"合在一起"起作用的**。少一个前提，结论就不成立。
所以 Lattice 不会把"预算有限"单独记成"推导出需求曲线"——那样会得出错误的学习路径。

### 4.3 卡 / cue

**同一个命题可以有多种问法，每种问法是一张"卡"。**

比如"边际效用递减"可以有：
- 「边际效用为什么递减？」（问原因）
- 「买第二个包子的满足感为什么比第一个低？」（问应用）
- 「边际效用递减和需求曲线什么关系？」（问连接）

它们共享**同一份复习进度**——因为知识是一个，只是你能从不同角度想起来。
你答对了一种问法，不代表其他问法都行，所以 Lattice 会优先练你答得差的那种问法。

### 4.4 掌握度（mastery）

**它对你的判断：你理解这个命题的概率。**

- 范围 0–100%，永远带一个"不确定区间"（比如 72% ± 12）。
- 新命题从 50% 起步，区间很大——意思是"我还不知道"。
- **只有你作答、或用自己话解释，它才会变。**
- 光看不算。停留时间再长也不涨掌握度——这是故意的（§10.3）。

### 4.5 可用率（R）

**它对你的判断：此刻让你回想，你能想起来的概率。**

由复习历史 + 遗忘曲线算出。它随时间自然下降，复习后回升。

### 4.6 为什么要有两个数字

| 情况 | 掌握度 | 可用率 | 该怎么办 |
|---|---|---|---|
| 真懂了，也记得 | 高 | 高 | 别管它 |
| 真懂了，但要忘 | 高 | 低 | **复习**（不是重学） |
| 没懂，但背下来了 | 低 | 高 | **回头补先修**（复习没用） |
| 既没懂也没记住 | 低 | 低 | 从先修开始 |

一个数字给不出这四种建议。这是 Lattice 的设计前提。

### 4.7 前沿（frontier）

**现在可以开始学的命题集合。**

判定标准：它的所有先修命题，你都已经掌握到 70% 以上。

> 类比：你不会在没学过加法时被推"微积分"。前沿就是"你的知识边界上，已经够得着的那一圈"。

### 4.8 打断预算

**每天允许 Lattice 打扰你的额度。**

不是"每天推 3 张"，而是"今天还有多少打扰额度"：
- 新标签页几乎不扣分（你本来就打开了新标签页）；
- 页内角标扣中等；
- 系统通知扣最多；
- 你在看视频全屏、正在输入、页面在后台时，**不打扰**；
- 额度用完 → 当天静默（静默是默认状态）。

### 4.9 留白对照

有时 Lattice **故意不展示**一张卡（约 5%），用来做对照实验，验证"推送到底有没有用"。

它**不是为了省钱**，也不是 bug。你在 设置 → 隐私 里可以看到自己有没有被留白、以及为什么。
不想要可以关掉（关闭后，就无法测量效果，报告里会显示"样本不足"）。

## 5. 界面导览

### 5.1 新标签页（主界面）

```
┌────────────────────────────────────────────────────┐
│  Lattice          [今日 3] [前沿 12] [复习 7]    ⚙  │
├────────────────────────────────────────────────────┤
│                                                    │
│   边际效用为什么递减？                                │
│   ───────────────────────────────                  │
│                                                    │
│   [ 重来 ] [ 困难 ] [ 一般 ] [ 简单 ]                 │
│                                    为什么是这张？ →   │
├────────────────────────────────────────────────────┤
│  本周：掌握 18 · 已复习 42 · 到目标还差 12 个命题     │
└────────────────────────────────────────────────────┘
```

- 点 **⚙** 进设置。
- 点底部的周统计 → 打开详细报告（掌握度变化、校准、成本）。
- 卡片右上「为什么是这张？」展开解释：它属于哪个目标、缺了哪个先修、上次错在哪。

### 5.2 页内角标

在支持的页面上，右下角会出现一个不抢焦点的窄条：

```
┌─────────────────────────┐
│ 指针和引用传参的区别  ↵  │
└─────────────────────────┘
```

- 不点它，15 秒后自己消失（算一次"未响应"，轻微降权）。
- 悬停展开完整卡片；点击进入复习模式。
- 在视频全屏、输入框聚焦、页面隐藏时**不会出现**。
- 觉得烦：设置 → 表面 → 关闭页内角标，或调低推送强度。

### 5.3 通知

默认关闭。开启后，只在**打断预算充足且效用最高**时出现，每天最多 1 次。
通知里只有一个问题和两个按钮：`回答` / `稍后`。

### 5.4 设置页（六个标签）

| 标签 | 内容 |
|---|---|
| **模型** | provider、key、模型路由（哪个任务用哪个模型）、测试连接 |
| **投放** | 推送强度、每日额度、新学/复习比例、安静时段 |
| **表面** | 新标签页 / 页内角标 / 通知 的开关与站点白名单/黑名单 |
| **数据** | 存储位置、导出、导入、备份提醒、同步 |
| **隐私** | 遥测（默认关）、留白对照说明、数据删除、许可与致谢 |
| **关于** | 版本、更新检查、文档、反馈、许可证 |

### 5.5 图谱视图

扩展图标 → 「图谱」。你看到的是一张图：

- **圆点 = 命题**，大小 = 被依赖的程度（越基础越大）；
- **箭头 = 推理链**（箭头指向结论）；
- 颜色：
  - 灰色 = 未学
  - 蓝色 = 学过但掌握度低
  - 绿色 = 掌握度高
  - 橙色描边 = 快忘了（可用率低）
- 点一个圆点 → 右侧面板：命题原文、出处（哪份材料、哪一页）、它的前提与结论、你的两个数字。

**常用操作**：拖拽布局、双击重命名、框选合并（"这两个其实是一个东西"）、右键"标记为错误"。

### 5.6 路径视图

扩展图标 → 「路径」。如果你设了目标，这里显示从你当前位置到目标的最小依赖树：

```
你的目标：能独立复现这篇论文的实验
├─ ✅ 假设检验的基本逻辑          (掌握 91%)
├─ ✅ p 值的含义                  (掌握 84%)
├─ 🔵 置信区间的构造              (掌握 62%)   ← 现在在这里
│   ├─ ⬜ 抽样分布
│   └─ ⬜ 标准误
└─ ⬜ 多重比较校正
```

- ✅ = 够了，不教；🔵 = 正在学；⬜ = 还够不着。
- 点任意节点 → 「为什么现在学它」：它依赖谁、被谁依赖、离目标几步。
- 路径会随你掌握度变化**自动重算**，不需要手动维护计划。

## 6. 日常使用

### 6.1 捕获一段网页内容

1. 选中一段话（1–3 段最好，太长会拆出很多命题）。
2. 右键 → **「存入 Lattice」**，或按 `Alt+Shift+K`。
3. 弹出的候选清单里：
   - 每条前面有勾选；
   - 鼠标悬停可以看到"原文位置"（会高亮原文）；
   - 文字可直接改；
   - 觉得拆得不好 → 点「重新拆解」。
4. 「确认入库」。

> **提示**：一段话里如果塞了三个不同判断，Lattice 会拆成三条。这是好事——它们将来会被不同的链连起来。

### 6.2 导入 PDF

扩展图标 → 「添加材料」→ 拖入 PDF（或点选文件）。

- 文件在本地解析，**不会整份上传**；只有拆出来的句子会发给模型（若你用本地模型，则完全不出机器）。
- 扫描版 PDF（图片）无法解析文字，会提示你改用"手动建卡"。
- 一本书太多？先只处理你正在读的那一章。

### 6.3 导入笔记

- **Markdown 文件夹 / Obsidian vault**：设置 → 数据 → 导入 → 选文件夹。
  每个 `.md` 文件按标题层级拆成命题；`[[双链]]` 会被识别为"相关"提示（**不是**推理链，需你确认）。
- **Anki**（v1.0 起）：导入 `.apkg` 时保留复习历史与调度状态，命题会尽量对齐到已有图谱。

### 6.4 复习

1. 打开新标签页（或点扩展图标 → 「复习」）。
2. 看问题 → 心里回答 → 点「显示答案」。
3. 按真实感受选：`重来`（完全忘了）/ `困难` / `一般` / `简单`。
4. 下一张。

- 每天先清**到期复习**，再学**新命题**（比例默认 65:35）。
- 逾期积压永远优先——不会因为"新内容"把旧债盖掉。
- 一张卡最多出现 3 次/天（学习阶段除外），避免刷屏。

### 6.5 设一个目标，看路径

1. 扩展图标 → 「目标」→ 输入一句话，例如："三周后能独立证明中值定理"。
2. Lattice 会把它映射到图谱里已有的命题；映射不准时你可以手动改（点「不对，我要的是…」）。
3. 打开「路径」视图，你会看到最小依赖树，以及**现在该学哪个**。
4. 学完一个，路径自动更新；如果发现某个先修你其实不会，它会退回补。

> 没有合适的目标？用「我想搞懂…」也行。目标是用来**裁剪**的——没有目标，所有知识都同等重要，就没法排优先级。

### 6.6 处理一条错误命题

发现 Lattice 拆错了 / 记错了：

1. 在图谱或卡片里点该命题 → 右侧面板 → **「这条有问题」**。
2. 选类型：`拆错了` / `和另一条重复` / `原文没有这个意思` / `过时了`。
3. 提交后：
   - 重复 → 合并（保留全部出处）；
   - 过时 → 标记失效，旧记录仍可查（时间旅行）；
   - 拆错 → 删除该命题及其链，并影响后续同类抽取（作为负例）。
4. 你的更正会进入「待复核」，也会纠正同一个来源的后续抽取。

### 6.7 看周报

扩展图标 → 「报告」：

- **掌握度变化**：本周新增/提升/下降的命题；
- **薄弱环节**：掌握度低但被高度依赖的命题（"补上它，后面一串都会通"）；
- **校准**：你以为懂了但其实没懂的比例（例如"高估 12%"）；
- **成本**：本周 token 消耗，按任务分项；
- **留白对照**（若开启）：推送组 vs 留白组的延迟测验差异。

## 7. 复习机制详解

### 7.1 四档评级到底在评什么

| 你的感受 | 选择 | 对调度的含义 |
|---|---|---|
| 完全想不起来 / 想错了 | 重来 | 间隔重置，很快再出现 |
| 想起来了，但很费劲 / 差点忘 | 困难 | 间隔小幅增加 |
| 正常想起来 | 一般 | 间隔正常增加 |
| 秒答，毫不费力 | 简单 | 间隔大幅增加 |

**不要为了"看起来努力"选"重来"**——那会让这张卡天天出现，挤占新内容，并让调度模型低估你。
也不要为了快点选"简单"——它会在你真正忘掉的时候才出现。

### 7.2 为什么这张卡现在出现

点卡片右上「为什么是这张？」，你会看到三种原因之一：

1. **到期复习**：可用率掉到了目标值（默认 90%）以下；
2. **前沿新学**：它的先修都够了，而你还没学；
3. **薄弱补救**：你在这张卡上反复失败，或它的 cue 一直答不对。

如果原因写着"薄弱补救"且你已经很烦，说明该**改卡**而不是多复习——换一种问法（点卡片 → 编辑 → 添加一个更具体的 cue）。

### 7.3 为什么有的卡一天出现两次

- 你在**学习阶段**（第一次学）：会在 1 分钟、10 分钟后各出现一次，这是正常的"短期巩固"。
- 你点了「重来」：会进入重学步骤。
- 除此之外，同一张卡不会在同一天出现超过 3 次。

### 7.4 掌握度为什么不动

常见原因：
1. 你只是看了，没有作答——**看不算证据**（§10.3）；
2. 你答的是别的命题的题（比如先修题），它涨的是先修那个；
3. 新命题的区间很大，一次作答变化不明显；
4. 你在设置里开启过"手动锁定掌握度"。

## 8. 推送设置

### 8.1 推送强度

| 档位 | 每日额度 | 典型行为 |
|---|---|---|
| 保守（默认） | 低 | 主要靠新标签页；角标每天 0–2 次；无通知 |
| 平衡 | 中 | 新标签页 + 角标 3–5 次；通知可开 |
| 积极 | 高 | 全表面；通知最多 2 次/天 |

**建议从保守开始**。推送过多是这类产品最常见的死法，而"少推但每次都准"比"多推"有效得多。

### 8.2 安静时段

默认 23:00–08:00。安静时段内只有"你主动打开新标签页"才会出现内容，不主动打扰。

### 8.3 站点规则

- **黑名单**：这些网站上永不出现角标（例如网课、考试系统、视频会议）。
- **白名单**：只在这些网站上出现（更保守）。

默认黑名单包含：任何 `chrome://` / `edge://` 页面、支付页面、以及你手动添加的站点。

### 8.4 留白对照（重要）

约 5% 的候选卡会被**故意不展示**，作为对照组。目的是回答一个问题：**推送到底有没有用？**

- 你永远不会因此"少学"——留白的卡会稍后正常进入队列；
- 设置 → 隐私 里能看到自己的留白统计；
- 关闭后：报告里"效果验证"一栏会显示"未启用"，其余功能不受影响；
- 我们不会用留白来省钱（token 成本发生在抽取阶段，与展示无关）。

### 8.5 疲劳降级

如果连续跳过 3 次角标，或被"稍后"累计 5 次：
- 当天自动降级为"只在新标签页出现"；
- 第二天恢复；
- 连续 3 天降级 → 提示你调低推送强度。

## 9. 数据管理

### 9.1 数据存在哪

| 形态 | 位置 |
|---|---|
| Solo | 浏览器的 OPFS（源私有文件系统），按扩展的 origin 隔离 |
| Daemon | `~/.lattice/`（Windows：`%USERPROFILE%\.lattice\`），可用 `--data-dir` 改 |
| 同步（可选） | 你自己指定的存储：WebDAV / git 仓库 / Syncthing 目录 |

### 9.2 导出

设置 → 数据 → 导出，或 `lattice export`。

两种格式：

- **JSONL（事件日志）**：完整、可重放、可导入到另一台机器。**这是备份请用这个。**
- **Markdown**：人读版本，按主题分文件，含命题、推理链、你的作答历史摘要。适合放进 Obsidian / 提交到 git。

> **建议**：每月导出一次。浏览器"清除站点数据"、重装系统、换电脑，都靠它。

### 9.3 导入与合并

- 导入 JSONL 是**追加合并**：同一设备的事件按 ID 去重，不会重复计数。
- 从别人那里拿到的命题包（例如课程包）也是追加——不会覆盖你自己的复习历史。
- 冲突处理：没有"冲突"。事件是只追加的观察，合并就是取并集；派生数字重新计算。

### 9.4 多设备同步

v1.0 提供**协议 + 自托管**，不提供官方云服务。

最简单的方式（daemon 模式）：

```bash
# 在每台机器上使用同一个同步目录
lattice init --data-dir ~/Dropbox/lattice
# 或使用 git
cd ~/.lattice && git init && git add -A && git commit -m "sync"
```

同步时只传事件日志；各设备本地重算派生数据，因此不需要解决"谁的掌握度是对的"。

### 9.5 换电脑 / 重装

1. 旧机器：导出 JSONL。
2. 新机器：装好扩展 → 设置 → 数据 → 导入 → 选择 JSONL。
3. 等待重算（几千条事件通常 1–2 秒）。

### 9.6 删除

- **删除单个命题**：图谱 → 右键 → 删除（会提示它被哪些链引用）。
- **清空全部数据**：设置 → 隐私 → 删除全部数据 → 输入 `DELETE` 确认。
  - 立即从界面消失；
  - 7 天内可在设置里撤销；
  - 7 天后从存储中彻底删除，无法恢复。

## 10. 隐私与安全

### 10.1 什么会离开你的机器

| 动作 | 发出什么 | 发给谁 |
|---|---|---|
| 捕获/拆解 | 你选中的**文本片段**（以及页面标题、出处地址） | 你配置的模型 provider |
| 生成新问法 | 命题文本 + 它的链条邻域 | 同上 |
| 解释评分 | 命题 + 你的解释文本 | 同上 |
| 复习、调度、图谱 | **什么都不发** | —— |
| 更新检查 | 版本号（可在设置里关） | 项目发布页 |

**不会发出**：浏览历史、完整网页、完整 PDF、你的其他标签页、任何遥测。
用本地模型（Ollama / LM Studio）时，以上全部不出机器。

### 10.2 模型 key 存哪

- 默认存在扩展的独立存储命名空间（`chrome.storage.local`），**不与其他扩展共享**；
- 可选：让 daemon 代持 key（key 从不进入浏览器）；
- key 永远不会出现在导出的数据里——导出前会自动剔除敏感字段。

### 10.3 为什么"看"不算学习

Lattice 刻意**不让曝光影响掌握度**。原因：

- 曝光只能证明"你有机会看到"，不能证明"你理解了"；
- 如果曝光涨掌握度，产品会退化成"刷存在感"，而且读数会系统性高估；
- 所以曝光、停留、点击只进入「上下文账」，用来决定**何时打扰你**，不参与"你懂不懂"的判断。

这是本产品最重要的一条设计纪律。你可能觉得它"低估了你"，但长期看，它让你的学习报告可信。

### 10.4 留白对照的伦理

我们故意不展示 5% 的卡，这是唯一一处"对你隐瞒信息"的设计。它有三个约束：

1. 只用于测量，不用于省钱；
2. 被留白的卡之后仍会进入队列，你不会少学；
3. 可以在设置里一键关闭，并在隐私页看到全部留白记录。

## 11. 模型与成本

### 11.1 Lattice 不收费

没有账号、没有订阅、没有内购。你只需要为自己的模型 API 付费（或使用本地模型 = 零成本）。

### 11.2 哪个任务用哪个模型

设置 → 模型 → 模型路由。默认：

| 任务 | 默认档位 | 说明 |
|---|---|---|
| 拆解材料（extract） | **强模型** | 质量最敏感，省钱别省这里 |
| 判同（identify） | 便宜模型 | 只是判断"是不是同一个"，简单但上下文长 |
| 生成问法（cue） | 中档 | 影响复习体验 |
| 解释与评分 | 中档 | 每次复习若开启才调用 |
| 路径叙述 | 便宜模型 | 只把结果讲成人话 |

### 11.3 成本大概多少（按 token 估，不含具体单价）

| 操作 | 输入 token | 输出 token | 备注 |
|---|---|---|---|
| 整页捕获（约 3000 字） | ~6k | ~1.5k | 一次 |
| 单条命题生成问法 | ~0.5k | ~0.2k | 每命题一次 |
| 一次复习 | **0** | **0** | 复习不调用模型 |
| 自由解释评分（可选） | ~1k | ~0.3k | 每次开启时 |

> 关键点：**复习本身不花钱。** 花钱的是"把材料变成结构"和"生成问法"，这两件事一次性完成，之后反复复习都是本地计算。

### 11.4 省钱技巧

1. 拆解用强模型，判同/生成问法用便宜模型（路由可分别设置）；
2. 关闭"自由解释评分"（它只是弱证据，权重 0.4）；
3. 用本地模型做判同与生成，只在拆解时用云端；
4. 一次只捕获你**正在读**的那几段，而不是整本书；
5. 复习不需要网络，飞机上也能用。

### 11.5 本地模型

设置 → 模型 → 选「OpenAI 兼容」→ 填 `http://127.0.0.1:11434/v1`（Ollama）或 LM Studio 的地址。
拆解质量取决于模型能力；7B 级模型通常能拆简单材料，复杂材料建议 14B 以上。

## 13. 高级用法

### 13.1 CLI（需要 daemon）

```bash
lattice init [--data-dir DIR]      # 初始化数据目录
lattice serve [--port 7878]        # 启动本地服务（扩展自动连接）
lattice capture <file|url|->       # 从文件/网址/stdin 捕获
lattice due [--limit 20]           # 列出到期复习
lattice review                     # 终端交互式复习
lattice plan --goal "..."          # 生成/查看最小先修树
lattice explain <proposition-id>   # 这条命题的出处、链条、你的两个数字
lattice graph [--format dot|json]  # 导出图谱
lattice export [--format jsonl|md] [--out FILE]
lattice import <file>
lattice replay [--from DATE]       # 重放事件日志，重算全部派生数据
lattice eval calibration|retention|cost
lattice doctor                     # 自检：存储、模型连通性、数据一致性
```

**示例：查一张卡的来龙去脉**

```bash
lattice due --limit 5        # 先看今天到期的前 5 张
lattice explain p_7f3a      # 查其中一张：出处、链条、你的两个数字
```

### 13.2 MCP（让其他 AI 工具读你的学习记录）

把 Lattice 的学习者模型接到 Claude Code、Cursor 或任何支持 MCP 的客户端：

```json
{
  "mcpServers": {
    "lattice": {
      "command": "npx",
      "args": ["-y", "@lattice/mcp"],
      "env": { "LATTICE_DATA_DIR": "~/.lattice" }
    }
  }
}
```

可用工具（**只读为主**）：

| 工具 | 作用 |
|---|---|
| `lattice_search` | 在命题/链条里搜索 |
| `lattice_due` | 列出到期复习 |
| `lattice_mastery` | 某命题的掌握度/可用率/出处 |
| `lattice_plan` | 某目标的最小先修树 |
| `lattice_explain` | 为什么这张现在出现 |
| `lattice_capture` | 写入新命题（**需二次确认**，默认关闭） |

> 安全提示：MCP 客户端能看到你的学习记录。只接入你信任的客户端。

### 13.3 插件

v1.0 只开放两类插件接口：

- **Surface（表面）**：读前沿与复习队列，上报展示/点击事件 —— 用来做桌面浮层、手机小组件、终端 UI；
- **Ingest（输入）**：产生"捕获"事件 —— 用来接 Readwise、Kindle 标注、播客转写等。

**不开放**"插件直接写入知识账"——那会让图谱质量失控。插件要改知识，只能走"候选 → 用户确认"。

### 13.4 自托管同步

见 §9.4。协议是"事件日志的并集 + 本地重算"，因此任何能同步文件的工具都能当同步层。

## 14. 疑难排查

### 14.1 新标签页没有卡片

按顺序检查：

1. **有没有材料？** 没有命题就不会有卡。去捕获或导入。
2. **有没有到期内容？** 「复习 0」且没有前沿新学 → 正常，说明你今天清空了。
3. **是不是安静时段？** 23:00–08:00 不主动推；但你手动打开新标签页仍会显示。
4. **打断预算用完了？** 设置 → 投放 看余额。
5. **被疲劳降级了？** 连续跳过 3 次会降级，第二天恢复。

### 14.2 捕获没反应

- 页面是 `chrome://`、扩展商店、PDF 内置查看器 → 浏览器禁止注入，正常现象；
- 没选中文字 → 快捷键需要有选区；
- 页面在 iframe 里 → 暂不支持跨 iframe 选区（v1.0 限制）；
- 站点被你在黑名单里 → 设置 → 表面 检查。

### 14.3 拆解失败 / 一直转圈

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示"未配置模型" | 没填 key | 设置 → 模型 |
| 401/403 | key 无效或过期 | 重新填 |
| 429 | 额度用尽/限流 | 换模型或稍后 |
| 超时 | 材料太长 | 分段捕获（每次 1–3 段） |
| 返回空 | 页面是图片/加密内容 | 用手动建卡 |

### 14.4 提示"这段已经处理过"

覆盖账本生效了——同一段文本不会重复抽取。若你确实想重抽（比如换了更强的模型）：
设置 → 数据 → 覆盖记录 → 删除对应条目，再捕获一次。

### 14.5 掌握度一直不动

见 §7.4。最常见原因：**你只看了，没作答。** 去看一张卡并选一档评级，或做一道测验。

### 14.6 推送太多 / 太少

- 太多：设置 → 投放 → 降一档；或关掉角标；或缩短活跃时段。
- 太少：升一档；检查是否在安静时段；检查黑名单。
- **不建议**为了"多学"调到积极——推送过量会导致你开始无视它，那时所有信号都失效。

### 14.7 图谱很碎（一堆孤立节点）

说明材料是"零散句子"而不是"有结构的文本"。两个办法：
1. 用图谱的「合并」把同义命题并起来；
2. 导入一份有章节结构的材料（教材/讲义），链条会自然形成。

> 一个孤立节点也可能完全正常——有些事实本来就是"基础命题"，没有前提。

### 14.8 换了电脑/重装，数据没了

OPFS 数据不随扩展同步。如果没有导出过，无法恢复——这是本地优先的代价。
**请每月导出一次。**

### 14.9 扩展更新后数据还在吗

在。数据在 OPFS，按 origin 存储，与扩展版本无关。
但**卸载扩展**可能删除其存储（取决于浏览器），所以卸载前务必导出。

### 14.10 daemon 连不上

- `lattice serve` 是否在跑？
- 端口是否被占？换 `--port`；
- 防火墙是否拦了回环？一般不会；
- token 是否过期？重启 daemon 会重新握手。

### 14.11 模型费用涨得很快

- 检查路由：是不是把"判同/生成"也配了强模型？
- 关掉"自由解释评分"；
- 改用本地模型做判同；
- `lattice eval cost` 看哪个任务最贵。

### 14.12 时间/时区不对

Lattice 用本地时区计算"今天"。若你跨时区旅行，日界线会跟着变，可能造成一天多/少几张卡。
设置 → 投放 → 时区 可锁定。

## 15. 常见问题

**Q：它会上传我的浏览历史吗？**
不会。扩展不监听你的导航，也不记录你访问过什么。只有当你主动捕获时，才会保存**那一页的地址**作为出处。

**Q：它在监视我吗？**
没有遥测、没有账号、没有服务器。你可以用系统工具（或 `lattice doctor`）验证它只连你配置的模型地址。

**Q：能离线用吗？**
复习、调度、图谱、导出全部离线。只有"拆材料 / 生成问法 / 解释评分"需要模型，可用本地模型做到完全离线。

**Q：我的 PDF 会整份发给模型吗？**
不会。文件在本地解析，只发送拆解出的句子（以及页码）。用本地模型时不出机器。

**Q：会收费吗？**
不收费。你自付模型 API 费用；本地模型零成本。

**Q：能多设备同步吗？**
可以，自托管（WebDAV / git / Syncthing）。没有官方云。

**Q：和 Anki 冲突吗？**
不冲突，但两边调度各自独立，同一张卡会在两边分别安排。v1.0 起可导入 Anki 复习历史。

**Q：为什么我的掌握度只有 50%？**
新命题的先验就是 50%（且区间很大）。它代表"我还不知道"，不是"你只懂一半"。

**Q：为什么它不给我推更多？**
因为它认为现在推你也不会看，或者你正在做别的事。静默是默认状态。

**Q：能改卡片内容吗？**
能。点卡片 → 编辑 → 改问法或答案。改命题原文会记录为一次更正事件，历史仍可查。

**Q：能删除我不想学的材料吗？**
能。删命题、删来源、清空全部数据，都在设置 → 数据/隐私 里。

**Q：它和 ChatGPT 有什么区别？**
ChatGPT 每次对话都不记得你；Lattice 的目标就是"记得你"，并且把"记得"变成可检查、可导出的数据。

**Q：开源吗？用什么许可？**
是，Apache-2.0。你可以自己构建、审计、部署、二次开发。

**Q：我能贡献吗？**
可以。最需要的是：材料格式解析器、新的表面插件、以及"这条抽取错了"的真实样本。

**Q：为什么有时故意不显示卡片？**
留白对照（§8.4），用来验证推送有效性。可关闭。

---

## 16. 卸载与数据清除

**只想停用**：设置 → 表面 → 关掉全部表面。数据保留。

**要清空数据**：设置 → 隐私 → 删除全部数据（7 天撤销窗口）。

**要卸载扩展**：

1. **先导出**（设置 → 数据 → 导出 JSONL）；
2. `chrome://extensions` → 移除；
3. 如果用过 daemon：`rm -rf ~/.lattice`。

> 卸载扩展通常会一并删除其 OPFS 数据，**不可恢复**。

## 附录 A：数据文件结构（简表）

> 完整规范见项目 `docs/data-format.md`。这里只给查错用。

```
~/.lattice/
├─ events.jsonl        # 唯一真相：所有事件，只追加
├─ lattice.db          # SQLite：四本账的投影（可删除后重放重建）
├─ settings.json       # 本地设置（不含 key）
└─ exports/            # 你导出的备份
```

事件长这样（每条一行 JSON）：

```json
{"id":"01J...","device_id":"d1","seq":42,"occurred_at":"2026-11-24T09:12:33Z",
 "recorded_at":"2026-11-24T09:12:34Z","actor":"human","type":"review.rated",
 "subject_id":"p_7f3a","payload":{"cue_id":"c_11","grade":2,"elapsed_days":3.2}}
```

**重放**：

```bash
lattice replay --from 2026-01-01
```

这会用同一份日志重算所有派生数字。如果重算结果和当前不一致，说明数据被外部改过 —— 以重放结果为准。
