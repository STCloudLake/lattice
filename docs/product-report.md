## §0 待批准范围：M0（本文档的第一道闸门）

> 其余章节描述的是 **v1.0 全貌**（约 12 周）。M0 只做下面这一小块，批准即开工。

### M0 交付物（2 周）

| # | 交付 | 验收 |
|---|---|---|
| 1 | **存储可行性判定**：`sqlite-wasm + OPFS + FTS5` 在 Chrome/Edge 最新版的实测结论 | 有 go/no-go 报告；no-go 则给出 IndexedDB+BM25 替代方案 |
| 2 | `@lattice/core` 骨架：四本账类型、事件日志、投影、FSRS（`ts-fsrs`）、Beta 掌握度、确定性 ID | 单测 line coverage ≥ 80% |
| 3 | MV3 扩展骨架：新标签页复习流 + 四档评级 + 测验 | 导入 200 条命题可正常出题 |
| 4 | 导入/导出：命题 JSON 导入、JSONL 导出 | 导出的日志可重放，投影一致 |
| 5 | `lattice replay` + 校准报告（Brier/ECE） | 命令可跑，输出报告 |
| 6 | 删除与重置：清空全部数据 | 清空后无残留（OPFS 目录为空） |

> 说明：M0 的 `lattice replay` / `lattice eval` 是最小开发用 CLI（验收需要）；
> 面向用户的完整 CLI（`due / review / plan / capture`）仍在 M2 交付。

### M0 明确不做

- ❌ 任何 LLM 调用（**M0 完全离线可验证**，命题用人工 JSON 导入）
- ❌ 网页/PDF 捕获、知识图谱抽取、路径规划、推送策略
- ❌ daemon、CLI 其它命令、MCP、同步、插件

### M0 为什么这样切

M0 的唯一目的是**证明"账本 + 重放 + 校准"这条数据主干成立**，并且把最大的技术不确定性（浏览器内 SQLite 持久化）提前证伪。
它不追求"看起来像个产品"——所以故意不含 LLM 与捕获。若 M0 的三条验收（持久化、重放一致、校准可算）任一不成立，后面 10 周的设计都要改。

### 工作量与风险

- 工作量：约 10 人日（2 周，单人）。
- 主要风险：① OPFS/SQLite-WASM 在主浏览器不稳定 → 有回退方案；② MV3 service worker 生命周期 → 已按"先落盘再上报"设计；③ 扩展商店审核 → M0 用开发者模式加载，不提交商店。

## §1 产品定义

### 1.1 一句话

**Lattice 是一个开源的、本地优先的学习者模型：它把你的知识拆成可追溯的命题与推理链，
用两套独立的数字分别描述"你懂没懂"和"你忘没忘"，然后把下一件该学的事，送到你本来就在的界面上。**

### 1.2 目标用户

| 用户 | 特征 | 主要痛点 | Lattice 给他的 |
|---|---|---|---|
| **碎片型学习者**（大学生、考证党） | 想学但启动困难，时间被短视频切碎 | 收藏了一堆资料从不打开 | 新标签页/通知里的 15 秒剂量，由模型决定推什么 |
| **深度型学习者**（研究生、工程师） | 读论文/教材，需要体系而不是卡片 | 卡片是孤立的，不知道先学什么 | 命题+推理链图、最小先修树、可解释的路径 |
| **自学者**（转行、兴趣） | 没有课程表，没有老师 | 不知道自己在哪、还差多少 | 目标 → 前沿(frontier) → 到目标的距离与时间估算 |

### 1.3 它解决的问题（按重要性）

1. **"不开始"**：产品出现在用户已经在的地方，用极小剂量降低启动成本。
2. **"学了就忘"**：FSRS 调度，但只作为"可用性"，不与"理解"混为一谈。
3. **"不知道学什么"**：目标 → 最小先修树 → 前沿，每一步能回答"为什么现在学它"。
4. **"懂了但想不起来 / 背了但没懂"**：两个独立的数字让这两种失败可被区分、可被针对。
5. **"数据不是我的"**：本地优先、纯文本可导出、可重放、可删除。

### 1.4 它不是什么

- **不是 Anki 替代品**：可以和 Anki 共存（M3 提供导入导出）。Anki 是"你告诉它复习什么"，Lattice 是"它决定你该学什么"。
- **不是 AI 聊天助手**：没有对话界面。LLM 只在抽取、判同、生成、解释四个位置出现。
- **不是课程平台 / 视频课**：不生产内容，只组织你已有的材料。
- **不是监控工具**：没有教师后台、没有班级看板、没有强制上报。
- **不是"AI 自动学习"**：它不会替你学。它替你做的只有"安排"。

### 1.5 产品形态

| 形态 | 组成 | 谁用 |
|---|---|---|
| **Solo（默认）** | 只装浏览器扩展。数据在浏览器 OPFS 里的 SQLite。 | 90% 用户 |
| **Daemon（进阶）** | 扩展 + 本地 `lattice` 进程。多出 CLI、MCP、同步、批量导入。 | 深度用户、开发者 |

两种形态共享同一份事件日志格式，迁移 = 导出/导入。

## §3 关键用户旅程

### 旅程 1：碎片型（林，大三，备考）

1. 装扩展 → 授权新标签页 → 填入自己的模型 key（或选本地模型）。
2. 把课程群里的一份 PDF 拖进扩展。"它正在拆解" → 约 30 秒后出现 40 条候选命题，
   她删掉 3 条明显重复的，确认。
3. 打开新标签页：一张卡「边际效用为什么递减？」，底部 `[懂了] [没懂] [稍后]`。
4. 答了一道单选，错了 → 看到解析 → Lattice 记下"这是误解，不是粗心"（她很快作答且选了错项）。
5. 三天后，同样的命题以**另一个 cue**（不同问法）再次出现，这次答对。
6. 周报：`掌握 18 个命题；最长漏洞：博弈论→纳什均衡链上缺 2 个前置`。

### 旅程 2：深度型（陈，研究生，读论文）

1. 装 daemon（`npx lattice`）→ 扩展自动连上 → 数据落在 `~/.lattice/`。
2. 在 arXiv PDF 里选中一段 → 右键"存入" → 候选命题带页码。
3. CLI：`lattice plan --goal "能独立复现这篇论文的实验"` → 输出最小先修树 + "现在该学：X（因为你缺 A→B）"。
4. 学到一半发现理解错了 → `lattice explain <id>` 看当初的推理链 → 标记更正 → 图里旧边被 supersede，历史仍可查。
5. `lattice eval calibration` → 发现自己"以为懂了"的命题系统性高估 12%，按建议调低自评权重。

### 旅程 3：自学者（王，转行，学编程）

1. 在 B 站看视频，展开字幕 → 点扩展：捕获字幕 → 命题入库。
2. 页内角标偶尔出现一行：「指针和引用在传参上的区别，你上次弄混了」→ 点击展开 15 秒卡。
3. 设目标"三个月内能独立写完一个带数据库的小项目" → 前沿列表明确到"函数指针"这种粒度。
4. 连续两天跳过推送 → 自动降级为只在新标签页出现，不再打扰。
5. 在终端里用 `lattice due` 复习了 12 张，然后 `lattice export` 备份。

## §4 与既有产品的功能对照

| 能力 | Anki | learnharness | 通用 AI tutor | **Lattice** |
|---|---|---|---|---|
| FSRS 调度 | ✅ 最强 | ✅（插件内） | ❌ | ✅ 官方实现 |
| 知识结构（命题/推理链） | ❌ 扁平牌组 | ✅ | ⚠️ 生成但不持久 | ✅ 可追溯、可合并 |
| 持久学习者模型 | ⚠️ 只有调度 | ❌ 刻意不存 | ❌ | ✅ 掌握度 + 可用率双数 |
| 路径规划 | ❌ 手动 | ✅ 会话内最小树 | ⚠️ 生成一份清单 | ✅ 跨会话、可重算 |
| 环境式推送（不主动打开） | ❌ | ❌ | ❌ | ✅ 打断预算 + 效用排序 |
| 注意力证据 | ❌ | ⚠️ 只有作答 | ❌ | ✅ 独立成账，不参与掌握判断 |
| 效果可证伪 | ❌ | ❌ | ❌ | ✅ 留白对照 + 延迟测验 |
| 本地优先 / 可导出 | ✅ | ✅ | ❌ | ✅ 事件日志纯文本 |
| 开源 | ✅ AGPL | ✅ AGPL | ❌ | ✅ Apache-2.0 |

**差异化的一句话**：别人要么有调度没结构，要么有结构没推送，要么有推送没测量。Lattice 只把这三件事接起来。

**v1.0 发布判据（Definition of Done）**
1. 三个里程碑的 P0 功能全部通过验收；
2. 校准报告显示 mastery 的 Brier 优于常数基线；
3. 留白对照跑满 ≥ 2 周且有结果（正、负、无结论都接受，但必须有）；
4. 50 条人工标注先修边的回归测试通过；
5. 导出的 JSONL 在另一台机器上能重放出相同投影；
6. 无未修复的 P0 安全/隐私问题；
7. 至少有 **1 个外部贡献者**的表层插件跑通（证明插件契约真的可用）。

## §6 非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 新标签页首屏 < 300ms（本地数据，无网络）；复习评分到下一张 < 100ms；整页捕获端到端 < 20s（含 LLM） |
| **容量** | 单实例 5 万命题 / 50 万事件；超过时提示归档（设计目标，M2 实测） |
| **可靠性** | 事件先落盘后上报；崩溃最多丢当前一次交互；重放结果确定（同输入同输出） |
| **离线** | 除 LLM 调用外全功能离线可用；复习与调度永远不依赖网络 |
| **隐私** | 默认零遥测；模型 key 仅存本地；捕获内容只在用户手势下发送 |
| **可访问性** | 键盘可达所有核心操作；对比度 ≥ WCAG AA；支持系统字体缩放 |
| **国际化** | v1.0 中英双语 UI；文档中英各一份 |
| **合规** | 不处理未授权内容；只存 span 与引用，不建全文库；提供数据删除 |
| **成本** | 复习路径 0 token；每次捕获的 token 预算在 UI 明示；支持本地模型降为零成本 |

## §7 明确不做（v1.0）

| 不做 | 理由 |
|---|---|
| 云端账号、社交、排行榜 | 与"本地优先、数据是你的"叙事冲突 |
| 自动后台爬取建库 | 版权与隐私风险；只接受用户主动提供 |
| 移动 App | 先把浏览器 + 桌面站住；M3 后再评估 |
| DKT/AKT/SAINT、RL 课程编排、完整 KST | 数据门槛差 3–4 个数量级（详见设计文档 §7.3） |
| 插件可写知识账 | 会让图质量失控；只开 `Surface` 与 `Ingest` |
| 对话式 tutor UI | 与产品定位冲突；解释用"展开"而非"聊天" |
| 教师监控后台 | `ETHICS.md` 明确拒绝 |
| 云同步托管服务（官方运营） | 只提供协议与自托管方案 |

## §8 成功度量

**北极星指标**：**day-30 留存正确率** —— 30 天前学过的命题，今天在不提示的情况下答对的比例。
（选它而不是 DAU/推送量，是因为它直接对应"有没有真的学会"，且无法靠多推刷出来。）

**护栏指标**（任何一项恶化都要回滚策略）：

| 指标 | 含义 | 红线 |
|---|---|---|
| 打断接受率 | 展示后被点击/停留的比例 | < 15% 视为打扰 |
| 连续跳过 | 用户连续划过 | ≥ 3 次立即降级 |
| 卸载/停用率 | 7 日内停用 | > 20% 需自省 |
| 误抽率 | 用户删除/更正的命题占比 | > 15% 需改抽取 |
| token 成本 | 每学到一个命题的花费 | 超过设定预算需提示 |
| 校准误差 | ECE | > 0.15 需重新拟合 |

**阶段性验证问题**（决定是否继续投入）：
1. M1 后：自动抽取的命题，用户接受率是否 > 70%？
2. M2 后：留白对照的 Δretention 是否显著为正？
3. M3 后：是否有第二个表面由外部贡献？

## §9 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 浏览器内 SQLite（OPFS）不稳定 | 中 | 高（M0 架构） | M0 第一件事就是判定；回退 IndexedDB+BM25 |
| 自动抽取质量不达 70% | 中 | 高（产品核心） | 预览确认 + 覆盖账本 + few-shot 纠正回灌 |
| 用户不愿装"要 key 的扩展" | 中 | 中 | 支持本地模型；提供"手动命题"零模型路径 |
| 环境式推送被认为"监视" | 中 | 高（声誉） | 本地优先、零遥测、明示留白对照、`ETHICS.md` |
| 单人维护 12 周路线图 | 高 | 中 | M0/M1 优先纯函数与测试；M2 起引入贡献者 |
| FSRS 参数在混合 cue 下预测失准 | 中 | 中 | 已在设计上限定"每命题一份调度"，M2 实测偏差 |
| 版权投诉（用户捕获付费内容） | 低 | 高 | 只存 span + 引用，不缓存全文，不提供分享 |

## §10 语义定义（全产品统一口径）

| 术语 | 定义 | 不要混淆 |
|---|---|---|
| 命题 proposition | 一个可以被"信以为真"的判断句 | 不是"概念名词"，不是"卡片" |
| 推理链 chain | 一组前提**联合**蕴含一个结论 | 不是"相关"，不是"A 单独蕴含 C" |
| 卡 / cue | 一个检索路线（问法），多对一挂在命题上 | 不是知识单位；同一命题可以有多张卡 |
| 掌握度 mastery | P(理解) 的后验，带区间 | 不是"正确率"，不是"熟练度" |
| 可用率 R | 此刻能想起的概率（FSRS） | 不等于掌握度 |
| 前沿 frontier | 先修已够、可以开始学的命题集合 | 不是"待办清单" |
| 打断预算 | 每日允许的打扰额度 | 不是"每日推送数量" |
| 留白对照 | 故意不展示的对照组 | 不是 bug，不是省成本手段 |
